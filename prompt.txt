
# 🗳️ Vidya Valley School — Election System: Full Coding Agent Prompt

---

## PROJECT OVERVIEW

Build a **local network election web application** for **Vidya Valley School (VVS)**, Pune. One computer acts as the **host/server**. All other computers (**slaves**) connect to it via the host's local IP in a browser. No internet required. Stack is **Django + MySQL**.

---

## TECH STACK

- **Backend:** Django 4.x
- **Database:** MySQL (`mysqlclient` or `PyMySQL`)
- **Frontend:** Django templates + plain CSS + minimal vanilla JS
- **Networking:** Django dev server bound to `0.0.0.0:8000`. Provide a `start.py` script that auto-detects local IP and prints it clearly.
- **No external CDN dependencies** — all fonts and assets must be local or inline.

---

## STARTUP FLOW — HOST vs SLAVE

When any computer opens the app at `http://<host-ip>:8000`, before anything else, it must go through a **startup screen**:

### Startup Screen (`/setup`)
- Full-page centered card with VVS logo
- Two big buttons: **"I am the Host"** and **"I am a Voting Station"**

**If Host:**
- Redirects to `/admin/login`
- Full admin access

**If Voting Station (Slave):**
- Shows a second screen: **"Select House for this Station"**
- Four large house buttons, each styled in their house color:
  - 🔵 Cheetah
  - 🔴 Jaguar
  - 🟠 Puma
  - 🟡 Sher
- Admin must enter a **station PIN** (set in Election Settings) to confirm the house selection — prevents students from changing the house themselves
- Once confirmed, the house is **locked into the browser session** for this station
- Station then shows `/vote/login` and from this point forward, all ballot logic uses the locked house
- A small badge is always visible in the corner showing: `🔵 Cheetah Station` (or whichever house) so it's clear which station it is
- The only way to change the house is to go back to `/setup` which again requires the PIN

## DATABASE MODELS

### `Student`
- `enrollment_number` (unique, CharField) — login key
- `has_voted` (BooleanField, default False)

### `Position`
- `name` (e.g. "Head Boy", "House Captain Boy")
- `scope` (choices: `school_wide` / `house_specific`)
- `house` (nullable — only for house_specific)
- `gender_category` (Boy / Girl / Open)
- `is_active` (BooleanField)

### `Candidate`
- `student` (FK to Student)
- `position` (FK to Position)
- `photo` (ImageField, optional)
- `bio` (TextField, optional, max 300 chars)
- `is_active` (BooleanField)

### `Vote`
- `voter` (FK to Student)
- `candidate` (FK to Candidate)
- `position` (FK to Position)
- `timestamp` (auto_now_add)
- **Unique constraint:** (`voter`, `position`)

### `ElectionSettings`
- `election_name`, `academic_year`
- `is_open` (BooleanField)
- `station_pin` (CharField) — 4–6 digit PIN required to set/change house on any slave station

## FEATURE SPECIFICATIONS

### Startup & Station Lock
- `/setup` — no session required, always accessible
- House selection requires PIN entry (validated against `ElectionSettings.station_pin`)
- Selected house stored in Django session as `station_house`
- Every vote-side view checks for `station_house` in session; if missing, redirects to `/setup`
- Station badge (house name + color dot) shown in top-right corner on all voting pages

### Student Login (`/vote/login`)
- Single enrollment number input
- Validates student exists, election is open, student hasn't voted
- On success: store student ID in session alongside `station_house`
- Error messages for: not found, already voted, election closed

### Ballot (`/vote/ballot`)
- Session-protected
- Shows student name + house badge at top
- **Section 1:** School-wide positions (4 cards)
- **Section 2:** `[Station House]` House Positions (4 cards, styled in house color)
- Each position = card with candidate radio options (photo or avatar placeholder, name, class)
- Submit button disabled until all 8 positions selected (JS validation)
- Votes saved atomically with `transaction.atomic()`; `has_voted` set to True; session cleared

### Confirmation (`/vote/confirm`)
- "✅ Vote recorded!" + student name + timestamp
- Session cleared after this page loads
- No back navigation

### Already Voted (`/vote/already-voted`)
- Shows name, time voted, green checkmark

### Admin Dashboard (`/admin/dashboard`)
- Stats cards: Total Students, Voted, % Turnout, Election Status
- Per-house turnout mini-cards (each styled in house color)
- Last 10 activity entries: "A student from [House] voted" — no names
- Auto-refresh every 30s via JS fetch

### Election Settings (`/admin/election`)
- Set name, academic year, open/close toggle
- Set/change **Station PIN** (shown masked, with reveal toggle)
- Optional start/end datetime
- "Reset All Votes" danger button (type "RESET" to confirm)

### Student Management (`/admin/students`)
- Table: Enrollment No., Name, House, Class, Voted, Time
- Add single student form
- Bulk CSV import (columns: `enrollment_number, full_name, house, class_grade`)
- Downloadable sample CSV template link
- Graceful error handling on import: skip bad rows, report count of skipped rows to admin
- Filter by house and voted status

### Candidate Management (`/admin/candidates`)
- Grouped by position
- Add: pick student, pick position, optional photo + bio
- Edit / Remove
- House color badge on house-specific positions

### Results (`/admin/results`)
- **Admin-only. Never exposed to students or stations.**
- Groups by position, shows vote count + animated percentage bar per candidate
- Leading candidate gets gold highlight border
- House positions use house color for bars
- Auto-refresh every 10s via `setInterval` fetching `/admin/results/data/` JSON endpoint

### Export (`/admin/export`)
- CSV: Position, Candidate, Enrollment No., Votes, Percentage
- PDF via `reportlab`: VVS logo, election name, date, results table
- Audit log CSV: Timestamp, House, Position (no candidate names)

### Audit Log (`/admin/audit`)
- Table: Timestamp, House, Position
- Filter by house and time range

## SECURITY & INTEGRITY

- DB-level unique constraint on (`voter`, `position`) — one vote per position per student
- `transaction.atomic()` on all vote submissions
- Session cleared immediately after vote cast
- All `/admin/` views require `request.user.is_staff`
- All `/vote/` views require `station_house` in session
- CSRF on all forms
- Station PIN required to assign or reassign a house to any station
- Students cannot access any admin route
- Session timeout: 30 minutes inactivity

## START SCRIPT (`start.py`)

```python
import subprocess, socket

def get_local_ip():
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    s.connect(("8.8.8.8", 80))
    ip = s.getsockname()[0]
    s.close()
    return ip

ip = get_local_ip()
print(f"\n{'='*50}")
print(f"  VVS Election System — RUNNING")
print(f"  Open on this machine : http://localhost:8000")
print(f"  Other computers join : http://{ip}:8000")
print(f"{'='*50}\n")
subprocess.run(["python", "manage.py", "runserver", "0.0.0.0:8000"])
```
